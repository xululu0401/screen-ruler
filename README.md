# 屏幕实尺

输入两块屏幕的对角线英寸和宽高比，比较物理宽高、矩形面积、完整画面面积、黑边和中心裁切。支持旋转、本地图片预览、参数备份和 CSV/PNG 导出。

默认数值是演示方案，不代表某款手机。只计算完整矩形，忽略圆角、挖孔、系统栏和播放器控件；不评估清晰度、亮度或握持感。两屏示意共用比例尺，并非显示器上的实际毫米尺寸。

## 计算
D=英寸×25.4；W=D×宽比/hypot(宽比,高比)，H 同理。完整显示按 min(W/内容宽,H/内容高) 缩放；铺满按 max 缩放并中心裁切。面积以 cm² 表示，黑边是屏幕未被画面覆盖比例，裁掉是原画面面积损失比例。

## 使用与隐私
直接打开 index.html。无依赖、无模型 API、无需登录。图片只在浏览器内预览，不上传、不存储；导出卡不包含图片。只有主动勾选记忆时才用 localStorage 保存参数，取消勾选删除本工具记录。

## 开发与验证
node build.cjs
node --test tests/core.test.cjs
